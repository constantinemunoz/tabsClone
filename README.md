# Battle Sim

A wobbly physics-comedy battle simulator that runs entirely in the browser.

```sh
npm install
npm run dev     # dev server at http://localhost:5173
npm run build   # static site in dist/
npm test        # unit tests (Vitest)
npm run bench   # headless simulation benchmark (Node 22+)
```

The full README (controls, architecture, how to add units/levels/maps, deployment) is written in
the final milestone. See PROGRESS.md for the current state.
